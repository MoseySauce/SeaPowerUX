SeaPowerUX

A BepInEx mod pack for Sea Power that adds new UI and improves the UI the game already has.

What's in the pack

Air Boss (Flight Deck Manager)

One window listing every ship and air base with a flight deck. Clicking a row opens the game's own flight deck panel, docked beside the list.

Picture-in-picture

Mirrors the main camera with no extra scene cost. Shows automatically when the fullscreen map covers the 3D view.

Window memory

Restores each window's saved position before it's first drawn, so it lands in place with no visible jump. Removable by design.

Shared Core

HUD-aware hiding, a shared toolbar, Set Default / Reset for the whole layout, desktop-style resizing, and docking — applied to the game's own windows, not just the pack's.

Get started

Requires BepInEx 5 (x64). Download the release, extract it, and run the installer for your system.
