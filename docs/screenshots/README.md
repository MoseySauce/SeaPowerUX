# Screenshots

Drop PNGs here with these exact names and `docs/index.html` picks them up automatically —
no HTML changes needed:

| File | Shows |
|---|---|
| `air-boss.png` | The Air Boss / Flight Deck Manager window |
| `pip.png` | The picture-in-picture window |
| `toolbar.png` | The shared toolbar and window chrome (resize, lock, docking) |
| `window-memory.png` | A window restored to a non-default saved position |

Roughly 1600px wide, 16:10, PNG or JPG. Until a file exists, its slot on the page shows a
"coming soon" placeholder instead of a broken image.
